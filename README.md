# Notre histoire — Antonio & Ericka

Un court métrage animé en scrollytelling pour l'anniversaire d'Ericka (17 novembre).

Un seul fichier `index.html` : SVG + CSS inline, animations GSAP/ScrollTrigger, défilement fluide Lenis et musique générée en Web Audio.

Ouvrir le site, faire défiler, et activer « ♪ Musique » en haut à droite.
